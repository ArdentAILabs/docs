Ardent creates instant, isolated copies of your production Postgres database — in seconds, right from your terminal.

Test migrations, run schema changes, and let coding agents like Claude Code and Cursor actually verify their database work — all against real data, without touching production.

No more shared staging databases. No more hand-maintained fixtures. An instant database for every task.

   I can use however I want without touching prod.

   like any Postgres database.

## How it works

Ardent replicates your database into a read replica, then creates isolated **branches** from that replica in seconds. Each branch is a full Postgres database with your real data — like branches in git.

```
Production DB → Replication → Read replica → Many branches (each in seconds)
```

The workflow mirrors git:

- **`ardent branch create`** — spin up an isolated database copy
- **`ardent branch switch`** — move between branches
- **`ardent branch info`** — see the connection URL and status
- **`ardent branch delete`** — clean up when you're done

Branches suspend after a few minutes of inactivity and wake instantly on reconnect. You pay storage only for the changes you make on a branch — so create as many as you need and throw them away freely.
