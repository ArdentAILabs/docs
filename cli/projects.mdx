Projects are the top-level grouping for connectors and branches. Most people start with one; the project commands matter once you manage several environments or teams.

### ardent project create

```bash
ardent project create <name>
```

The new project becomes your current project.

<Accordion defaultOpen={false} title="Example output">
```
✓ Project 'staging' created
```
</Accordion>

### ardent project list

```bash
ardent project list
```

Your current project is green and marked `*`. Offline, the CLI shows cached data and labels it: `⚠ Offline - showing cached data from …`.

### ardent project switch

```bash
ardent project switch staging
```

Your connector and branch selections belong to the old project, so they're cleared. If the new project has exactly one connector, Ardent selects it for you.

<Accordion defaultOpen={false} title="Example output (single connector in new project)">
```
Switched to project 'staging'

  Auto-selected connector 'staging-db'
```
</Accordion>

### ardent project delete

```bash
ardent project delete staging
```

<Warning>
  This runs immediately — there is no confirmation prompt. Check the name before you press enter.
</Warning>

<Accordion defaultOpen={false} title="Example output">
```
Deleting project...
✓ Project deleted
  Name: staging
```
</Accordion>
