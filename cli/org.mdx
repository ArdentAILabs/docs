Roles, from most to least access: `owner`, `admin`, `member`, `viewer`.

### ardent invite

Invite someone to your organization. The role is optional — it defaults to `member`:

```bash
ardent invite alice@company.com
ardent invite alice@company.com admin
```

<Accordion defaultOpen={false} title="Example output">
```
✓ Invite sent to alice@company.com
```
</Accordion>

### ardent invite list

Pending invites:

```bash
ardent invite list
```

<Accordion defaultOpen={false} title="Example output">
```
Pending invites:

  alice@company.com
    Role: member | Sent: 4/29/2026

```
</Accordion>

### ardent invite delete

Revoke a pending invite:

```bash
ardent invite delete alice@company.com
```

### ardent org members

Everyone in your organization:

```bash
ardent org members
```

<Accordion defaultOpen={false} title="Example output">
```
Organization members:

  vikram@company.com (Vikram)
    Role: admin

  alice@company.com
    Role: member

```
</Accordion>

### ardent org set-role

```bash
ardent org set-role alice@company.com admin
```

Only admins and owners can change roles.

### ardent org remove

```bash
ardent org remove alice@company.com
```

Only admins and owners can remove members.
